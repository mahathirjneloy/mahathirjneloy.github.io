// 03. Engineering In Action

Featured Robotics Project

IEEE NSU RAS Workshop Showcase
Autonomous & RC Platform

Bluetooth RC Car with Autonomous Obstacle Avoidance

Raspberry Pi Pico MicroPython L298N H-Bridge HC-05 & HC-SR04

Built as part of a 3-member engineering team during the IEEE NSU RAS "RC Car with Raspberry Pi Pico" workshop series. The project integrates dual DC gear-motor pairs, real-time wireless Bluetooth serial telemetry, and autonomous sonar-guided collision avoidance.

4-Wheel Chassis Powertrain: Two DC gear-motor pairs driven through an L298N dual H-bridge module, controlled via RP2040 PWM logic running MicroPython.
Wireless Telemetry: Implemented manual RC control over Bluetooth via HC-05 module receiving UART bytes (F/B/L/R/S) from the Serial Bluetooth Terminal app.
Dual-Mode State Machine: Extended firmware into a dual-mode system switchable on the fly over Bluetooth: RC mode for manual driving and Autonomous mode for collision avoidance.
Sensor Fusion Avoidance: HC-SR04 ultrasonic echo timing with voltage-divided safe 3.3V logic plus side IR sensors — stops, maneuvers away, and resumes forward path safely.
